## ⚙️ Процесс Работы (ШАГ ЗА ШАГОМ)

### Шаг 1: Выбор задачи
```bash
1. Откройте docs/TASK_STATUS.md
2. Найдите строку со статусом "❌ Pending" и "-" в колонке "Assigned To"
3. Выберите ОДНУ задачу (не берите много сразу)
4. Проверьте, что другой агент не работает над похожим (посмотрите "In Progress")
```

### Шаг 2: Заявка на задачу
**Обновите TASK_STATUS.md:**
- Измените "❌ Pending" → "🔄 In Progress"
- Добавьте ваш Identifier в "Assigned To" (например "Agent-Auto" или ваше имя)
- Заполните "Notes" если нужно
- Укажите timestamp в заголовке файла

**Пример обновления:**
```markdown
| M4-NPC-5 | Zombie AI behavior | 🔄 In Progress | Agent-X | Started work, checking NPC.cs |
```

### Шаг 3: Реализация
1. **Найдите оригинал в decompiled/:** (согласно `agents.md`)
   ```bash
   # Например для zombie AI
   grep -n "AI_003_Fighters" decompiled/Terraria/NPC.cs
   ```

2. **Портируйте честно (gold rule):**
   - Та же структура
   - Те же константы
   - Тот же порядок вычислений
   - Называйте функции как в оригинале (`AI_003_Fighters` → `ai_003_fighters`)

3. **Документируйте решения в `docs/ANALYSIS.md`:**
   ```markdown
   ## Non-obvious decision for Zombie AI
   
   Original uses banker's rounding (Math.Round). Documented to match source.
   ```

4. **Проверяйте перед коммитом:**
   ```bash
   cargo test --workspace           # Все тесты должны проходить
   TR_SHOT=1 cargo run             # Сделайте скриншот
   python tools/pixel_diff.py      # Сравните с оригиналом
   ```

### Шаг 4: Завершение задачи
1. **Отметьте в TASK_STATUS.md:**
   ```markdown
   Status: "✅ Done"
   Notes: "Committed in <commit_hash>"
   Assigned To: "- (completed)"
   Timestamp: обновите
   ```

2. **Создайте коммит:**
   ```bash
   git add .
   git commit -m "[M4-NPC-5] Implement zombie AI behavior
    
    - Ported from Terraria/NPC.cs AI_003_Fighters
    - Added day-burn mechanics verified against source
    - All tests passing, visual output matches original"
   ```

3. **Push'ните:**
   ```bash
   git push origin feature/m4-npc-5-zombie-ai
   ```

### Шаг 5: Новая задача
Вернитесь к Шагу 1 и повторите процесс.

## 🚫 ЧЕГО НЕЛЬЗЯ ДЕЛАТЬ

### Конфликты (STRICT NO)
```
❌ Два агента работают над ОДНОЙ задачей одновременно
❌ Дублирование реализации одной системы
❌ Одновременные изменения в одном файле
❌ Разные версии одного и того же поведения
```

### Общие ошибки
```
❌ Гадать поведение без проверки C# источника
❌ Оптимизировать до проверки правильности
❌ Использовать другие имена чем в оригинале
❌ Пропускать edge cases из оригинального кода
❌ Не документировать нетривиальные решения
```
